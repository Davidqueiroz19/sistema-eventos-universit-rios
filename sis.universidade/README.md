# Sistema de Eventos Universitários 

Projeto acadêmico desenvolvido para a divulgação de eventos, palestras, workshops e minicursos de uma instituição universitária.

## Tecnologias Utilizadas
- **HTML5** (Estruturação semântica)
- **CSS3** (Flexbox, Media Queries e design responsivo)

## Funcionalidades
- **Página Inicial (`index.html`):** Apresentação do portal e grid responsivo com cards para 6 eventos.
- **Programação (`programacao.html`):** Tabela detalhada dos horários utilizando mesclagem com `rowspan` e `colspan`.
- **Inscrição (`inscricao.html`):** Formulário interativo e responsivo para cadastro de participantes.
